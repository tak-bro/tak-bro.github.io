**에이전트가 묻고, 너는 휙 답한다.** 모든 코딩 에이전트의 질문을 한 수신함에, 폰에서도 판단할 수 있는 맥락과 함께.

## 무엇을 하나

에이전트가 사람 판단이 필요한 순간에 `hwip_ask`(MCP)나 `hwip ask`(CLI)를 부른다. 질문에는 선택지와 기본값, 요약과 추천이 담긴다. 답은 폰·워치·맥·웹 어디서든 한다.

내 Claude Code 에는 hwip 플러그인이 켜져 있어서, 알림·파일을 폰으로 보내고 폰에서 답을 받는다([플러그인·MCP 가이드](/docs/plugins)).

## 구성

| 부분 | 쓰는 것 |
|---|---|
| 앱 | iOS·macOS·watchOS(SwiftUI), Android(Kotlin·Compose) |
| 웹 | React·Vite 웹앱, Chrome 확장(MV3) |
| 서버 | TypeScript, AWS Lambda·SNS·SQS·API Gateway WebSocket. Zeph 서버를 바탕으로 했다 |
| 연결 | CLI(zeph-to/cli 포크), MCP 서버, 플러그인 |
