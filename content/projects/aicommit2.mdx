Git·YADM·Jujutsu 저장소에서 스테이징한 변경을 읽고 AI 로 커밋 메시지를 만든다. 핵심 기능과 구조는 [AICommits](https://github.com/Nutlope/aicommits) 에서 출발했다.

## 무엇을 하나

- 여러 AI 에 동시에 요청하고, 돌아온 메시지 중 하나를 고른다(Reactive CLI).
- OpenAI·Anthropic Claude·Google Gemini·Mistral·Ollama 등과 OpenAI API 호환 서비스, 로컬 Claude Code·Gemini CLI 를 쓴다.
- 커밋 전에 심각도를 붙인 코드 리뷰를 받는다.
- 이미 있는 커밋의 메시지를 다시 쓴다(`aicommit2 rewrite`).
- `prepare-commit-msg` 훅으로 건다.
- diff 를 압축해 토큰을 줄인다.

메시지를 고른 뒤 `Use selected message? (Ynerh)` 에서 키 하나로 커밋·취소·편집·다시 받기를 한다.
