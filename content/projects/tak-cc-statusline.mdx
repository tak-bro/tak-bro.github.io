Claude Code 아래에 한 줄을 그리고, 터미널이 좁으면 두 줄로 나눈다. 설치는 `npx -y tak-cc-statusline@latest` 한 번이다.

[xleddyl/claude-watch](https://github.com/xleddyl/claude-watch) 를 포크해 시작했다. 사용량을 받아 오는 부분, 색 체계, 처음 배치는 그쪽 것이다. 이 패키지는 npm 설치 한 줄, macOS·Linux 지원, 모델별 주간 한도, 좁을 때 두 줄로 나누는 배치, 폴더 이름 대신 세션 이름을 더했다.

## 한 줄에 있는 것

| 칸 | 출처 |
|---|---|
| 모델 · effort | Claude Code 가 보내는 모델 이름과 reasoning effort |
| 세션 · 브랜치 | Claude Code 의 세션 이름(`/rename` 으로 정한 이름), 없으면 폴더 이름. 브랜치는 `git symbolic-ref` |
| 컨텍스트 막대 | `context_window.used_percentage` |
| 계정 | 사용량을 받아 온 계정. 로그인을 바꿔 쓸 때 구분한다 |
| 5h / 7d % | Anthropic OAuth 사용량 엔드포인트(60초 캐시) |
| `!1d 17h` | 지금 속도면 창이 리셋 전에 100% 에 닿을 때 빨갛게 보이는 남은 시간 |
| 모델별 주간 % | 같은 엔드포인트의 모델별 주간 한도(예: `Fable 12%`). 플랜에 있을 때만 보인다 |

막대 색은 50% 미만 초록, 50% 이상 노랑, 75% 이상 장미색, 90% 이상 빨강이다.
