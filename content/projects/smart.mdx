## 1. Description

- 진행 기간 2015.07 ~ 2015.12
- 개발 언어 및 개발 환경: `C++`, `Qt Framework`, `Node.js`, `Arduino`
- 버전관리 툴: Git
- 개발 내용
  - 라즈베리파이와 Node.js, Express를 활용한 웹 서버 개발
  - Qt Framework를 활용한 안드로이드 모바일 앱 개발
    - `Qt Library(C++)`, `QML` 활용
  - Arduino 제작
    - `LUFA Framework`로 HID Firmware 개발
    - HID 이벤트를 전송하는 Arduino 스케치 프로그램 개발
