## 다루는 것

- **원칙** — 이 설정 전체를 받치는 원칙과 그 근거가 된 사고 기록
- **에이전트 설정** — Claude Code·pi·opencode 의 규칙·훅·서브에이전트
- **워크플로우** — 작업 하나가 계획에서 머지까지 가는 길
- **지식 루프** — 끝난 작업의 기록이 지식베이스로 증류돼 다음 플랜으로 돌아오는 한 바퀴
- **플러그인·MCP** — 켜 두고 쓰는 Claude Code 플러그인과 MCP 서버
- **Herdr·키맵** — 터미널 작업 공간과 단축키, macOS 키보드·Ghostty·Karabiner·Neovim
