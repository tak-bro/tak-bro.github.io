[herdr](https://herdr.dev) 는 에이전트 멀티플렉서예요. tmux 처럼 탭과 pane 을 나누지만, 사이드바가 pane 마다 어떤 에이전트가 돌고 있는지, 지금 일하는 중인지 제 답을 기다리는지를 보여 줘요. 저는 Ghostty 안에서 herdr 를 띄우고 에이전트 세션을 전부 그 안에서 굴려요.

<HerdrDemo label="herdr 화면 녹화: pane 을 나누고 Claude Code·opencode·pi 를 띄운 뒤, 프로젝트를 오가고 pane 을 확대하고 사이드바를 접는 장면이에요." />

화면 아래 자막은 Cmd 키를 앞에, 같은 동작의 prefix 키를 괄호에 적었어요. 녹화는 Ghostty 밖에서 해서 prefix 키로 했어요.

키 설정은 대부분 기본값을 써요. 바꾼 것은 키 반복 속도와 입력 자동 교정, 터미널에서 Option·Cmd 키가 가는 곳 정도예요. 이 페이지는 실제 설정 파일에 있는 것만 적어요.

## 동작 원리

### 키 입력은 네 층을 지나요

키 입력은 아래 순서로 지나가요. 층마다 키를 바꿀 기회가 있어요.

<KeyLayersDiagram />

- **Karabiner-Elements** 는 OS 보다 앞에서 키를 바꿔요. 저는 리맵 없이 기기 설정에만 써요.
- **macOS** 는 키 반복과 텍스트 입력 규칙을 정해요. `defaults write` 로 바꾸고, `~/Library/KeyBindings/DefaultkeyBinding.dict` 로 문자 입력을 바꿔요.
- **Ghostty** 는 `keybind` 로 키를 자기 동작에 묶거나, 터미널 안 프로그램에 다른 시퀀스로 넘겨요.
- **Neovim** 은 받은 키를 자기 키맵으로 해석해요.

### 키는 두 갈래로 들어가요

herdr 단축키에는 두 가지 입력이 있어요.

- **prefix 키** — `ctrl+space` 를 누른 뒤 한 글자. tmux 와 같은 방식이고 어느 터미널에서나 동작해요.
- **Cmd 키** — `Cmd+T`·`Cmd+D` 처럼 맥 앱에서 익숙한 키. 터미널은 보통 Cmd 키를 앱 안으로 넘기지 않아서, 그대로는 herdr 에 닿지 않아요.

Cmd 키를 쓰려고 Ghostty 의 **key table** 을 써요. `herdr` 테이블이 켜져 있는 동안만 Ghostty 가 Cmd 키를 [kitty keyboard protocol](https://sw.kovidgoyal.net/kitty/keyboard-protocol/) 이스케이프 시퀀스(`CSI <키 코드>;<수식자>u`, 방향키는 `CSI 1;<수식자><A-D>`)로 바꿔 herdr 에 보내요. 테이블이 꺼져 있으면 같은 키가 Ghostty 의 원래 동작(새 탭 등)을 해요.

<KeyPathDiagram />

수식자 값은 `1 + shift(1) + alt(2) + ctrl(4) + cmd(8)` 이에요. `Cmd` 만 누르면 `9`, `Cmd+Shift` 면 `10` 이에요.

### 테이블은 herdr 를 띄울 때 켜요

테이블을 손으로 켜고 끄는 키(`Cmd+Shift+H`)도 있지만, 평소에는 셸 함수가 대신해요. `herdr` 를 실행하면 AppleScript 로 지금 Ghostty 터미널의 테이블을 켜고, herdr 가 끝나면 꺼요. `herdr status` 같은 하위 명령이나 herdr 안의 셸(`HERDR_ENV` 가 있음)에서는 아무것도 하지 않아요.

### 사이드바 브랜치는 타이머 스크립트가 채워요

에이전트 행 두 번째 줄에 pane 의 git 브랜치를 보여 주려고 `$branch` 라는 사용자 토큰을 써요. herdr 는 이 토큰을 스스로 채우지 않아요. 그래서 탭 바 오른쪽에 아무것도 출력하지 않는 command 항목을 하나 두고, 이 항목이 5초마다 `pane-branch.sh` 를 돌려요. 스크립트는 에이전트 pane 마다 브랜치를 읽어 `herdr pane report-metadata` 로 보고해요. 토큰에는 30초 TTL 이 있어서, 스크립트가 멈추면 브랜치 표시도 저절로 사라져요.

## 내 설정

### herdr 단축키

| 동작 | prefix 키 | Cmd 키 |
|---|---|---|
| 새 탭 | `prefix c` | `Cmd+T` |
| 탭 닫기 | `prefix Shift+X` | `Cmd+Shift+W` |
| 이전·다음 탭 | `prefix p`·`prefix n` | `Cmd+Shift+[`·`Cmd+Shift+]` |
| 탭 1~9 로 이동 | `prefix 1..9` | `Cmd+1..9` |
| 세로·가로 분할 | `prefix v`·`prefix -` | `Cmd+D`·`Cmd+Shift+D` |
| pane 닫기 | `prefix x` | `Cmd+W` |
| pane 이동 | `prefix h/j/k/l` | `Cmd+Alt+방향키` |
| 다음·이전 pane | `prefix Tab`·`prefix Shift+Tab` | `Cmd+]`·`Cmd+[` |
| pane 확대 | `prefix z` | `Cmd+Shift+Enter` |
| pane 크기 조절 | — | `Cmd+Ctrl+방향키` |
| 새 워크스페이스 | `prefix Shift+N` | `Cmd+Shift+N` |
| 워크스페이스 찾아가기 | `prefix g` | `Cmd+K` |
| 이전·다음 워크스페이스 | — | `Cmd+Shift+↑`·`Cmd+Shift+↓` |
| 워크스페이스 1~9 | `prefix Shift+1..9` | `Alt+1..9` |
| 사이드바 토글 | `prefix b` | `Cmd+B` |
| lazygit 팝업 | — | `Cmd+Shift+G` |
| 에이전트 계정 전환 | — | `Cmd+Shift+A` |

`prefix` 는 `ctrl+space` 예요. 마지막 두 줄은 herdr 의 사용자 명령(`[[keys.command]]`)이에요. 계정 전환은 제가 만든 `tak-bro.account-switch` 플러그인이 Claude Code·Codex 로그인을 바꿔요.

`Cmd+Ctrl+방향키` 는 창 관리자 Rectangle 의 기본 단축키(`⌃⌘←`·`⌃⌘→` 로 창을 왼쪽 위·오른쪽 위 모서리로)와 겹쳐요. 그대로 두면 Rectangle 이 키를 가로채서 herdr 에 닿지 않아요. 그래서 dotfiles 의 `macos-defaults.sh` 가 Rectangle 의 모서리 단축키 네 개를 비워 둬요.

### herdr 설정

사이드바는 두 패널이에요. 위의 spaces 패널이 프로젝트와 브랜치를 보여 주고, 아래 agents 패널은 누가 돌고 있는지를 앞에 둬요. 에이전트 이름은 종류마다 색을 다르게 하고, 상태 글자는 제가 봐야 할 때(`blocked`, `done`)만 보여요. 기본 브랜치(`main`·`master`·`develop`)는 흐리게, 작업 브랜치는 접두어(`feat`·`fix`·`hotfix`)마다 색을 줘요.

### Ghostty

herdr key table 말고 키에 관련된 Ghostty 설정은 세 가지예요.

| 설정 | 하는 일 |
|---|---|
| `keybind = super+arrow_up=scroll_page_lines:-1` | `Cmd+↑` 로 한 줄 위로 스크롤(iTerm 과 같게) |
| `keybind = super+arrow_down=scroll_page_lines:1` | `Cmd+↓` 로 한 줄 아래로 스크롤 |
| `macos-option-as-alt = true` | Option 키를 Alt 로 보내요. herdr 의 `Alt+1..9` 워크스페이스 이동이 이걸로 동작해요 |

파일 앞부분이 herdr 테이블이에요. 뒷부분은 herdr 와 상관없는 Ghostty 자체 설정이에요.

### 셸 함수

dotfiles 의 `zsh/.zshrc` 에서 herdr 함수만 옮겨요. 나머지는 herdr 와 상관없는 셸 설정이고, 비밀 값은 추적하지 않는 `~/.zshrc.local` 에 따로 둬요.

```zsh title="~/.zshrc"
herdr() {
  local tid=""
  # 세션을 여는 호출(인자 없음 또는 --옵션)일 때만. `herdr status` 같은 하위 명령은 그대로 통과.
  if [[ "$TERM_PROGRAM" == "ghostty" && -z "$HERDR_ENV" ]] \
     && { (( $# == 0 )) || [[ "$1" == -* ]]; } \
     && (( $+commands[osascript] )); then
    tid=$(osascript \
      -e 'tell application "Ghostty"' \
      -e 'set t to focused terminal of selected tab of front window' \
      -e 'perform action "activate_key_table:herdr" on t' \
      -e 'return id of t' \
      -e 'end tell' 2>/dev/null)
  fi

  command herdr "$@"
  local rc=$?

  if [[ -n "$tid" ]]; then
    osascript \
      -e 'on run argv' \
      -e 'tell application "Ghostty"' \
      -e 'set m to every terminal whose id is (item 1 of argv)' \
      -e 'if (count of m) > 0 then perform action "deactivate_key_table" on item 1 of m' \
      -e 'end tell' \
      -e 'end run' "$tid" >/dev/null 2>&1
  fi
  return $rc
}
```

### macOS 키보드

dotfiles 의 `macos-defaults.sh` 가 키보드 설정을 한 번에 걸어요.

- 키를 누르고 있으면 악센트 문자 팝업 대신 반복 입력이 나와요(`ApplePressAndHoldEnabled false`). 반복은 빠르게 시작해 빠르게 이어져요(`InitialKeyRepeat 15`, `KeyRepeat 2`).
- 자동 대문자·스마트 대시·마침표 자동 입력·스마트 따옴표·자동 고침을 꺼요. 코드나 명령을 칠 때 글자가 바뀌지 않게 하려는 거예요.
- 대화상자에서도 `Tab` 으로 모든 컨트롤을 오가요(`AppleKeyboardUIMode 3`).
- `Cmd+Ctrl+D` 사전 팝업을 꺼요.
- 한국어 자판에서 백틱 자리 키가 `₩` 를 입력하지 않고 `` ` `` 를 입력하게 해요. 마크다운과 셸에서 백틱을 자주 쓰기 때문이에요. 재시동해야 적용돼요.

```sh title="macos-defaults.sh (키보드 부분)"
# Enable full keyboard access for all controls
# (e.g. enable Tab in modal dialogs)
defaults write -g AppleKeyboardUIMode -int 3

# Disable press-and-hold for keys in favor of key repeat
defaults write -g ApplePressAndHoldEnabled -bool false

# Set a blazingly fast keyboard repeat rate
defaults write -g KeyRepeat -int 2
defaults write -g InitialKeyRepeat -int 15

# Disable automatic capitalization
defaults write -g NSAutomaticCapitalizationEnabled -bool false

# Disable smart dashes
defaults write -g NSAutomaticDashSubstitutionEnabled -bool false

# Disable automatic period substitution
defaults write -g NSAutomaticPeriodSubstitutionEnabled -bool false

# Disable smart quotes
defaults write -g NSAutomaticQuoteSubstitutionEnabled -bool false

# Disable auto-correct
defaults write -g NSAutomaticSpellingCorrectionEnabled -bool false

# Disable Cmd+Ctrl+D Dictionary popup
defaults write com.apple.symbolichotkeys AppleSymbolicHotKeys -dict-add 70 '<dict><key>enabled</key><false/></dict>'

# Map ₩ (Won sign) to ` (Backtick) for Korean keyboards
mkdir -p ~/Library/KeyBindings
echo '{"₩" = ("insertText:", "`");}' > ~/Library/KeyBindings/DefaultkeyBinding.dict
```

원본 스크립트는 `DefaultkeyBinding.dict` 가 이미 있으면 덮어쓰지 않아요. 위에서는 그 분기를 뺐어요.

### Karabiner-Elements

리맵 규칙은 하나도 없어요. 외장 키보드가 연결되면 맥북 내장 키보드를 끄는 기기 설정(`disable_built_in_keyboard_if_exists`)만 있어요. 외장 키보드를 노트북 위에 올려 둘 때 내장 키가 눌리지 않게 하려는 거예요. 기기 세 대에 같은 설정을 걸었어요.

설정 파일은 이 사이트에 싣지 않아요. 기기를 가리키는 식별자(제조사·제품 ID, 블루투스 주소)가 들어 있기 때문이에요. 직접 걸려면 Karabiner-Elements 설정의 기기 목록에서 그 키보드를 고르고, 내장 키보드를 끄는 옵션을 켜요. 설정 파일에는 `disable_built_in_keyboard_if_exists: true` 로 남아요.

### Neovim

[LazyVim](https://github.com/LazyVim/LazyVim) 을 쓰고, 키맵은 LazyVim 기본값 그대로예요. `lua/config/keymaps.lua` 에는 개인 키맵이 없어요. 기본 키맵 목록은 [LazyVim 의 keymaps.lua](https://github.com/LazyVim/LazyVim/blob/main/lua/lazyvim/config/keymaps.lua) 에 있어요.

LazyVim 보다 먼저 불리는 `settings.lua` 에는 편집 옵션만 있어요. 키 입력에 닿는 것은 `ttimeoutlen = 0`(Esc 뒤에 키 코드를 기다리지 않음) 한 줄이에요. `clipboard = "unnamedplus"` 는 yank·삭제·붙여넣기가 시스템 클립보드를 쓰게 해요. 줄 끝 주석의 "except yank" 와 달리 yank 도 포함돼요.

## 확인

### herdr

1. Ghostty 에서 `herdr` 를 실행해요. `Cmd+T` 를 눌러 Ghostty 탭이 아니라 herdr 탭이 생기면 key table 이 켜진 거예요.
2. herdr 를 끝내고 다시 `Cmd+T` 를 눌러요. 이번에는 Ghostty 탭이 생겨야 해요(테이블이 꺼짐).
3. 작업 브랜치에 있는 레포에서 에이전트를 띄워요. 5초 안에 사이드바 에이전트 행 둘째 줄에 접두어를 뺀 브랜치 이름이 나와요.
4. 브랜치 보고가 안 되면 스크립트가 읽는 값을 직접 봐요.

```sh
herdr pane list | jq '.result.panes[] | select(.agent != null) | {pane_id, cwd: (.foreground_cwd // .cwd)}'
```

### 키보드

1. 아무 입력창에서 `a` 를 누르고 있어요. 악센트 팝업 없이 `aaaa…` 가 빠르게 반복되면 키 반복 설정이 걸린 거예요.
2. TextEdit 같은 일반 입력창에서 백틱 키를 눌러요. `₩` 가 아니라 `` ` `` 가 나와야 해요.
3. Ghostty 에서 출력이 긴 명령을 실행한 뒤 `Cmd+↑` 를 눌러요. 한 줄씩 위로 올라가요.
4. 설정 값을 직접 읽어요.

```sh
defaults read -g KeyRepeat          # 2
defaults read -g InitialKeyRepeat   # 15
defaults read -g ApplePressAndHoldEnabled  # 0
```
