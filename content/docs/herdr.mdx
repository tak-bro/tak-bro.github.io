[herdr](https://herdr.dev) 는 에이전트 멀티플렉서예요. tmux 처럼 탭과 pane 을 나누지만, 사이드바가 pane 마다 어떤 에이전트가 돌고 있는지, 지금 일하는 중인지 제 답을 기다리는지를 보여 줘요. 저는 에이전트 세션을 전부 그 안에서 굴려요.

화면 아래 자막은 Cmd 키를 앞에, 같은 동작의 prefix 키를 괄호에 적었어요.

## 동작 원리

### 사이드바는 제가 봐야 할 pane 만 표시해요

에이전트를 여럿 띄우면 문제는 "지금 누가 저를 기다리나"예요. herdr 사이드바는 pane 마다 에이전트 종류와 상태를 보여 주는데, 저는 상태 글자를 `blocked`(제 답을 기다림)와 `done` 일 때만 보이게 해 뒀어요. 일하는 중인 pane 은 조용하고, 제가 손대야 하는 pane 만 글자가 떠요. 브랜치도 같은 생각이에요. 기본 브랜치(`main`·`master`·`develop`)는 흐리게, 작업 브랜치는 접두어(`feat`·`fix`·`hotfix`)마다 다른 색으로 보여요.

### `/team` 워커도 이 안에 떠요

[`/team`](./workflow.mdx) 을 치면 팀장 세션이 이 herdr 안에 워커 pane 을 직접 띄워요(`herdr agent start`). 워커는 첫 프롬프트부터 팀장과 동료의 이름을 알고, herdr 탭을 닫으면 Claude 워커도 같이 끝나요. 팀장은 워커 화면을 스크립트로 읽어(`team.sh peek`) 30분 넘게 busy 인 워커를 걸린 것으로 보고 들여다봐요.

### 사이드바 브랜치는 타이머 스크립트가 채워요

에이전트마다 worktree 가 달라서, 어느 pane 이 어느 브랜치에서 일하는지가 사이드바에 보여야 해요. 에이전트 행 두 번째 줄에 그 브랜치를 보여 주려고 `$branch` 라는 사용자 토큰을 써요. herdr 는 이 토큰을 스스로 채우지 않아요. 그래서 탭 바 오른쪽에 아무것도 출력하지 않는 command 항목을 하나 두고, 이 항목이 5초마다 `pane-branch.sh` 를 돌려요. 스크립트는 에이전트 pane 마다 브랜치를 읽어 `herdr pane report-metadata` 로 보고해요. 토큰에는 30초 TTL 이 있어서, 스크립트가 멈추면 브랜치 표시도 저절로 사라져요.

### 계정은 키 하나로 바꿔요

`Cmd+Shift+A` 는 제가 만든 herdr 플러그인 `tak-bro.account-switch` 를 불러요. Claude Code·Codex 로그인 프로필을 키 하나로 바꾸고, 이미 돌고 있는 세션도 30초 안에 새 계정을 집어요. 한 계정의 사용량 창이 차면 브라우저 재로그인 없이 다른 계정으로 넘어가요. pane 마다 `$acct` 배지가 지금 어느 계정을 쓰는지 보여 줘요.

## 확인

1. 작업 브랜치에 있는 레포에서 에이전트를 띄워요. 5초 안에 사이드바 에이전트 행 둘째 줄에 접두어를 뺀 브랜치 이름이 나와요.
2. 브랜치 보고가 안 되면 스크립트가 읽는 값을 직접 봐요.

```sh
herdr pane list | jq '.result.panes[] | select(.agent != null) | {pane_id, cwd: (.foreground_cwd // .cwd)}'
```
