[herdr](https://herdr.dev) is an agent multiplexer. Like tmux it splits tabs and panes, but its sidebar also shows which agent runs in each pane and whether it is working or waiting for my answer. I run every agent session in it.

## How it works

### The sidebar marks only the panes I need to look at

With several agents running, the question is who is waiting on me. herdr's sidebar shows each pane's agent and state, and I set the state text to show only for `blocked` (waiting for my answer) and `done`. Panes that are working stay quiet, and only the ones I need to touch carry text. Branches follow the same idea: default branches (`main`, `master`, `develop`) fade out, and working branches take a colour by prefix (`feat`, `fix`, `hotfix`).

### `/team` workers start in here too

When I type [`/team`](./workflow.mdx), the lead session starts worker panes inside this herdr itself (`herdr agent start`). The workers know the names of the lead and of each other from their first prompt, and closing the herdr tab ends the Claude workers too. The lead reads worker screens through a script (`team.sh peek`) and treats a worker that has been busy for more than 30 minutes as stuck and looks in.

### A timer script fills in the sidebar branch

Each agent works in its own worktree, so the sidebar has to show which pane works on which branch. To show that branch on the second line of an agent row, I use a custom token, `$branch`. herdr does not fill this token itself. So the right side of the tab bar has a command entry that prints nothing, and it runs `pane-branch.sh` every 5 seconds. The script reads the branch of each agent pane and reports it with `herdr pane report-metadata`. The token has a 30-second TTL, so the branch disappears on its own if the script stops.

### One key switches the account

`Cmd+Shift+A` calls `tak-bro.account-switch`, a herdr plugin I wrote. It swaps Claude Code and Codex login profiles with one key, and sessions already running pick up the new account within 30 seconds. When one account's usage window fills up, I move to another without logging in again in a browser. A `$acct` badge on each pane shows which account it uses.

1. Start an agent in a repo that is on a working branch. Within 5 seconds, the second line of its sidebar row shows the branch name without its type prefix.
2. If no branch shows, look at the values the script reads.

```sh
herdr pane list | jq '.result.panes[] | select(.agent != null) | {pane_id, cwd: (.foreground_cwd // .cwd)}'
```
