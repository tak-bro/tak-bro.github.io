키 설정은 대부분 기본값을 쓴다. 바꾼 것은 키 반복 속도와 입력 자동 교정, 터미널에서 Option·Cmd 키가 가는 곳 정도다. 이 페이지는 실제 설정 파일에 있는 것만 적는다. herdr 단축키와 Ghostty key table 은 [Herdr](./herdr.mdx) 가이드에 있다.

## 동작 원리

키 입력은 아래 순서로 지나간다. 층마다 키를 바꿀 기회가 있다.

```text
키보드 ──▶ Karabiner ──▶ macOS (키 반복·KeyBindings) ──▶ Ghostty (keybind) ──▶ 셸·herdr·Neovim
```

- **Karabiner-Elements** 는 OS 보다 앞에서 키를 바꾼다. 나는 리맵 없이 기기 설정에만 쓴다.
- **macOS** 는 키 반복과 텍스트 입력 규칙을 정한다. `defaults write` 로 바꾸고, `~/Library/KeyBindings/DefaultkeyBinding.dict` 로 문자 입력을 바꾼다.
- **Ghostty** 는 `keybind` 로 키를 자기 동작에 묶거나 터미널 안 프로그램에 다른 시퀀스로 넘긴다.
- **Neovim** 은 받은 키를 자기 키맵으로 해석한다.

## 내 설정

### macOS 키보드

새 맥에서는 `macos-defaults.sh` 가 키보드 설정을 한 번에 건다.

- 키를 누르고 있으면 악센트 문자 팝업 대신 반복 입력이 나온다(`ApplePressAndHoldEnabled false`). 반복은 빠르게 시작해 빠르게 이어진다(`InitialKeyRepeat 15`, `KeyRepeat 2`).
- 자동 대문자·스마트 대시·마침표 자동 입력·스마트 따옴표·자동 고침을 끈다. 코드나 명령을 칠 때 글자가 바뀌지 않게 하려는 것이다.
- 대화상자에서도 `Tab` 으로 모든 컨트롤을 오간다(`AppleKeyboardUIMode 3`).
- `Cmd+Ctrl+D` 사전 팝업을 끈다.
- 한국어 자판에서 백틱 자리 키가 `₩` 를 입력하지 않고 `` ` `` 를 입력하게 한다. 마크다운과 셸에서 백틱을 자주 쓴다. 재시동해야 적용된다.

```sh title="macos-defaults.sh (키보드 부분)"
# Enable full keyboard access for all controls
# (e.g. enable Tab in modal dialogs)
defaults write -g AppleKeyboardUIMode -int 3

# Disable press-and-hold for keys in favor of key repeat
defaults write -g ApplePressAndHoldEnabled -bool false

# Set a blazingly fast keyboard repeat rate
defaults write -g KeyRepeat -int 2
defaults write -g InitialKeyRepeat -int 15

# Disable automatic capitalization
defaults write -g NSAutomaticCapitalizationEnabled -bool false

# Disable smart dashes
defaults write -g NSAutomaticDashSubstitutionEnabled -bool false

# Disable automatic period substitution
defaults write -g NSAutomaticPeriodSubstitutionEnabled -bool false

# Disable smart quotes
defaults write -g NSAutomaticQuoteSubstitutionEnabled -bool false

# Disable auto-correct
defaults write -g NSAutomaticSpellingCorrectionEnabled -bool false

# Disable Cmd+Ctrl+D Dictionary popup
defaults write com.apple.symbolichotkeys AppleSymbolicHotKeys -dict-add 70 '<dict><key>enabled</key><false/></dict>'

# Map ₩ (Won sign) to ` (Backtick) for Korean keyboards
mkdir -p ~/Library/KeyBindings
echo '{"₩" = ("insertText:", "`");}' > ~/Library/KeyBindings/DefaultkeyBinding.dict
```

원본 스크립트는 `DefaultkeyBinding.dict` 가 이미 있으면 덮어쓰지 않는다. 위에서는 그 분기를 뺐다.

### Ghostty

herdr 밖에서 키에 관련된 Ghostty 설정은 세 가지다.

| 설정 | 하는 일 |
|---|---|
| `keybind = super+arrow_up=scroll_page_lines:-1` | `Cmd+↑` 로 한 줄 위로 스크롤(iTerm 과 같게) |
| `keybind = super+arrow_down=scroll_page_lines:1` | `Cmd+↓` 로 한 줄 아래로 스크롤 |
| `macos-option-as-alt = true` | Option 키를 Alt 로 보낸다. herdr 의 `Alt+1..9` 워크스페이스 이동이 이걸로 동작한다 |

Ghostty 설정 파일 전체는 [Herdr 가이드](./herdr.mdx#ghostty-key-table)에 있다.

### Karabiner-Elements

리맵 규칙은 하나도 없다. 외장 키보드가 연결되면 맥북 내장 키보드를 끄는 기기 설정(`disable_built_in_keyboard_if_exists`)만 있다. 외장 키보드를 노트북 위에 올려 둘 때 내장 키가 눌리지 않게 하려는 것이다. 기기 세 대에 같은 설정을 걸었다.

설정 파일은 이 사이트에 동기화하지 않는다. 기기를 가리키는 식별자(제조사·제품 ID, 블루투스 주소)가 들어 있기 때문이다. 직접 걸려면 Karabiner-Elements 설정의 기기 목록에서 그 키보드를 고르고 내장 키보드를 끄는 옵션을 켠다. 설정 파일에는 `disable_built_in_keyboard_if_exists: true` 로 남는다.

### Neovim

[LazyVim](https://github.com/LazyVim/LazyVim) 을 쓰고, 키맵은 LazyVim 기본값 그대로다. `lua/config/keymaps.lua` 에는 개인 키맵이 없다. 기본 키맵 목록은 [LazyVim 의 keymaps.lua](https://github.com/LazyVim/LazyVim/blob/main/lua/lazyvim/config/keymaps.lua) 에 있다.

LazyVim 보다 먼저 불리는 `settings.lua` 에는 편집 옵션만 있다. 키 입력에 닿는 것은 `ttimeoutlen = 0`(Esc 뒤에 키 코드를 기다리지 않음) 한 줄이다. `clipboard = "unnamedplus"` 는 yank·삭제·붙여넣기가 시스템 클립보드를 쓰게 한다. 줄 끝 주석의 "except yank" 와 달리 yank 도 포함된다.

## 확인

1. 아무 입력창에서 `a` 를 누르고 있는다. 악센트 팝업 없이 `aaaa…` 가 빠르게 반복되면 키 반복 설정이 걸린 것이다.
2. TextEdit 같은 일반 입력창에서 백틱 키를 누른다. `₩` 가 아니라 `` ` `` 가 나와야 한다.
3. Ghostty 에서 출력이 긴 명령을 실행한 뒤 `Cmd+↑` 를 누른다. 한 줄씩 위로 올라간다.
4. 설정 값을 직접 읽는다.

```sh
defaults read -g KeyRepeat          # 2
defaults read -g InitialKeyRepeat   # 15
defaults read -g ApplePressAndHoldEnabled  # 0
```
